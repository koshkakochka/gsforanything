# Spark (vendored)

`spark.module.js` is [Spark](https://sparkjs.dev/) 2.4.0, a three.js Gaussian
splat renderer (MIT license). Upstream: https://github.com/sparkjsdev/spark

Loaded through the app import map as `@sparkjsdev/spark` (dynamic import, only
when a splat file is opened). It expects `three` and `three/addons/` in the
import map.
